项目

AI-Pub 智能公众号管理系统

面向公众号运营者的智能客服中台：微信消息经「关键词规则 → 大模型生成 → 兜底话术」 三级决策后自动回复，并提供公众号配置、菜单同步、素材管理、消息检索与数据统计。
  • 四层算法：N-gram 分词 → TF-IDF + 余弦相似度意图识别 → 词典情感分析 → 多因子融合决策
  • 消息可靠性：RabbitMQ 手动 ACK + 死信队列 + msgId 幂等去重
  • access_token 三层缓存：Redis 缓存 + 分布式锁防击穿 + TTL 提前异步续期
  • 敏感字段 AES-256-GCM 加密入库；JWT 无状态认证 + 角色鉴权
  • 95 个测试用例（单元 + 集成），Docker Compose 一键部署，Prometheus + Grafana 监控
